Customer Transaction Prediction

📌 Project Overview

This project focuses on predicting customer transaction outcomes using machine learning techniques. The goal is to analyze customer transaction data, identify patterns, and build predictive models that can support data-driven business decisions.

The project demonstrates the application of data preprocessing, exploratory data analysis, feature engineering, and machine learning classification algorithms to solve a business-oriented prediction problem.

🎯 Objectives

Analyze customer transaction data to identify meaningful patterns and trends.

Perform data cleaning and preprocessing to prepare the dataset for modeling.

Build and evaluate machine learning classification models.

Compare model performance using evaluation metrics.

Identify a suitable model for predicting customer transaction outcomes.

🛠️ Technologies Used

Programming Language: Python

Data Analysis: Pandas, NumPy

Data Visualization: Matplotlib, Seaborn

Machine Learning: Scikit-learn, XGBoost

Development Environment: Jupyter Notebook

🔍 Project Workflow

Data Collection: Loaded the customer transaction dataset for analysis.

Data Preprocessing: Cleaned the data and prepared features for model training.

Exploratory Data Analysis (EDA): Examined data distributions, patterns, and relationships.

Feature Engineering: Prepared relevant features for machine learning models.

Model Building: Trained and compared the following classification algorithms:

Logistic Regression

Decision Tree Classifier

XGBoost Classifier

Model Evaluation: Evaluated model performance using accuracy and a confusion matrix.

Model Comparison: Compared the results to understand the strengths and limitations of each model.

📈 Key Findings

Logistic Regression achieved approximately 91.31% accuracy.

XGBoost achieved approximately 91.11% accuracy.

The Decision Tree model achieved approximately 83.57% accuracy.

Comparing multiple models helped identify differences in predictive performance.

Accuracy alone may not fully reflect performance when transaction classes are imbalanced, so additional metrics such as precision, recall, and F1-score are also important.
